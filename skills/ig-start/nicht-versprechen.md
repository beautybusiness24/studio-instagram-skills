# Nicht versprechen

Diese Liste lesen alle Skills, bevor sie einen Text ausgeben. Sie ist kein
Rechtstext und steht in keinem Beitrag. Sie sorgt dafür, dass ein Studio
nichts behauptet, was es nicht halten kann. Texte mit diesen Wörtern werden
umformuliert, bevor sie der Nutzerin gezeigt werden.

## Wörter und Behauptungen, die raus müssen

| statt | besser |
| --- | --- |
| für immer, dauerhaft haarfrei, nie wieder Haare | dauerhafte Reduktion, deutlich weniger Haare, bei den meisten Kundinnen |
| garantiert, 100 %, hundertprozentig, sicher wirksam | bei den meisten, in der Regel, erfahrungsgemäß |
| schmerzfrei, völlig schmerzfrei, ohne Schmerzen | gut verträglich, die meisten beschreiben es als Wärme oder kurzes Zwicken |
| ohne Nebenwirkungen, ohne Risiko | gut verträglich, mögliche Rötung klingt meist nach wenigen Stunden ab |
| heilt, Heilung, kuriert, therapiert, medizinisch | hilft bei, verbessert das Hautbild, kosmetisch |
| Wunder, Wundermittel, magisch | das konkrete Ergebnis nennen |
| ärztlich empfohlen, klinisch bewiesen, wissenschaftlich belegt | nur, wenn eine echte Quelle vorliegt, die genannt werden kann |
| FDA-zertifiziert | darf nicht verwendet werden, so etwas gibt es für Geräte nicht |
| Anti-Aging mit Zeitangabe („10 Jahre jünger“) | frischer, glatter, ausgeruhter |
| Fett weg, Abnehmen, Kilos verlieren | straffer, Umfang reduziert |
| Narben entfernen, Falten entfernen | Narben sichtbar mildern, Falten glätten |
| Akne heilen | unreine Haut verbessern |
| Cellulite beseitigen | Hautbild bei Cellulite verbessern |
| besser als beim Arzt, ersetzt den Hautarzt | nicht verwenden |
| Preise anderer Studios abwerten („Billigstudios“) | eigenen Preis erklären |

## Behandlungen, die ein Kosmetikstudio nicht bewirbt

Botox, Hyaluron-Unterspritzung, Fadenlifting, Lipolyse und alles, was unter
die Haut geht, sind Sache von Ärztinnen und Heilpraktikerinnen. Wenn eine
Nutzerin so etwas anbietet, nachfragen, wer behandelt, und ohne diese Angabe
keinen Text dazu schreiben.

## Vorher-Nachher-Bilder

Nur eigene Kundinnen, nur mit deren Einverständnis, nie Fotos aus dem
Internet oder vom Gerätehersteller als eigene Ergebnisse. Wenn die Nutzerin
kein eigenes Bild hat, kein Vorher-Nachher-Format vorschlagen.

## Zahlen

Keine Zahl erfinden: keine Kundinnenanzahl, keine Prozentangabe, keine
Bewertung, kein Preis. Wenn eine Zahl fehlt, `{{deine Zahl}}` in den Text
setzen und sagen, dass sie fehlt. Eine Zahl aus dem Studio-Profil darf
verwendet werden.

## Kundinnen

Keine Namen, keine erkennbaren Geschichten einzelner Kundinnen ohne deren
Einverständnis. „Eine Kundin“ reicht. Keine Diagnosen über Dritte.
